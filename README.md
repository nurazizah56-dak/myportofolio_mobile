## Deskripsi

`myportofolio_mobile` adalah aplikasi mobile multiplatform yang dibangun menggunakan **Flutter**. Aplikasi ini menampilkan halaman utama portofolio dengan identitas pemilik dan tombol navigasi menuju berbagai fitur portofolio (Education, Tambah Education, Logout).

Proyek ini merupakan bagian dari mata kuliah **Pemrograman Berbasis Platform (PBP)** Semester Gasal 2026/2027, Fakultas Ilmu Komputer, Universitas Indonesia.

## Setup & Cara Menjalankan

### Prasyarat
- Flutter SDK (sudah terinstall, verifikasi dengan `flutter doctor`)
- Google Chrome (untuk menjalankan di web)

### Langkah-langkah

1. Clone repositori ini:
   ```bash
   git clone https://github.com/nurazizah56-dak/myportofolio_mobile.git
   cd myportofolio_mobile
   ```

2. Jalankan di Google Chrome:
   ```bash
   flutter run -d chrome
   ```

3. Untuk memeriksa kualitas kode:
   ```bash
   flutter analyze
   ```
